# University Navigation & Study Abroad Portal

A full-stack web platform designed to help students explore and apply to top universities in the USA and UK.

## Features
- University search and browsing
- Scholarship information
- Visa guidance
- Accommodation services
- Application assistance
- Appointment booking
- User login & signup system

## Technologies Used
- PHP
- HTML
- CSS
- MySQL

## How to Run
1. Clone the repository
2. Import the database using `db_config.php`
3. Run on a local server (XAMPP or WAMP)
4. Open `index.html` in your browser
